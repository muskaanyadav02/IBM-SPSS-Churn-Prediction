# Customer Churn Prediction using IBM SPSS Modeler

## College Project

This project focuses on predicting customer churn using **IBM SPSS Modeler** and the **CHAID (Chi-squared Automatic Interaction Detection)** algorithm.

## Objective

The objective of this project is to develop a predictive model that can identify customers who are likely to churn.

## Software Used

- IBM SPSS Modeler
- Microsoft Excel

## Algorithm Used

**CHAID (Chi-squared Automatic Interaction Detection)**

CHAID is a decision-tree-based classification technique used to identify relationships between a target variable and predictor variables.

## Project Workflow

The project follows these main steps:

1. Import the customer dataset into IBM SPSS Modeler.
2. Select and prepare the required data.
3. Define the field types and roles.
4. Build the CHAID model.
5. Generate the churn model nugget.
6. Use deployment data to apply the trained model.
7. Generate customer churn predictions.
8. Identify customers who are at higher risk of churn.
